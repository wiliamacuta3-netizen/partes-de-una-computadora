# partes-de-una-computadora
que funcionalidad tienen unas partes de una computadora

MEMORIA RAM:
la memoria ram puede guardar la informacion temporalmenta

DISCO DURO:
guarda la informacion permanentemente

MOUSE:
nos ayuda a controlar la frechita del monitor

TECLADO:
nos ayuda a escribir en la computadora

FUENTE DE PODER:
nos ayuda a que la pantalla se mantenga encendida

TARGETA MADRE:
es la que mantiene unida muchos cables para que la computadora funcione
